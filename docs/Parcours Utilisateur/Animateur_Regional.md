# Animateur Régional
1. Il se connecte au compte de son organisme. 
2. Il suit les modifications apportées par les gestionnaires dans les dépôts. 
3. Il va se rendre sur la page de carte des données que les gestionnaires ont publié. 
4. Il va se rendre sur la page "export" et exporter la base régionale. 
5. De son export, il vérifie les définitions des standards, et les corrige si besoin.
